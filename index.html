Frequently asked questions

What to know about MarketScope

Is MarketScope available to install today?

MarketScope is currently in development. This website describes the intended product and does not offer a public installation or claim that the extension is ready for release.

Does MarketScope have Etsy API approval?

API approval and access are not claimed here. Any future integration will depend on Etsy's review, the permissions granted, and applicable API terms.

Can it show exact sales for competing shops?

Only information that Etsy makes available and authorizes the app to use can be presented as verified data. Private competitor orders and exact sales figures are not promised.

Will historical data be available?

Historical tracking can only report observations actually available or collected with permission. MarketScope will not imply it has a complete historical record when it does not.

Is MarketScope affiliated with Etsy?

No. MarketScope is an independent project and is not affiliated with, endorsed by, or sponsored by Etsy, Inc.
